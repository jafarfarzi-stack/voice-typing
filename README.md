# تایپ صوتی — آفلاین (Persian/English Voice Typing)

تایپ صوتی کاملاً **آفلاین** با رابط **دوزبانه** (فارسی / English).
بدون اینترنت کار می‌کند و متن را مستقیم در هر برنامه‌ای که باز است می‌نویسد.

> **زبان رابط** از combo «زبان» پیروی می‌کند: `فارسی` → فارسی، `English` → English.
> با تغییر زبان، تمام برچسب‌ها، دکمه‌ها، پیام‌ها و متن راهنما همان لحظه عوض می‌شوند.

---

## نصب

```bash
pip install -r requirements.txt
python app.py
```

بار اول، وقتی F8 را بزنید، برنامه می‌پرسد که مدل را دانلود کند یا نه.
بعد از آن دیگر هیچ اینترنتی لازم نیست.

اگر پکیج‌ها را دستی نصب می‌کنید:

```bash
pip install pyaudio numpy Pillow pyperclip pystray keyboard faster-whisper vosk
```

| موتور | حجم مدل | دقت فارسی | سرعت | توضیح |
|---|---|---|---|---|
| **Whisper small** | ~480 MB | **خیلی خوب** | متوسط | پیشنهادی |
| Whisper base | ~145 MB | خوب | سریع | اگر کم‌حجم می‌خواهید |

مدل Whisper را از داخل برنامه هم می‌توانید عوض کنید ( combo box بالای پنجره).

## راهنمای سریع

1. زبان را انتخاب کنید (فارسی / English)
2. `F8` را بزنید (پنجره مینیمایز می‌شود)
3. حرف بزنید — متن خودکار تایپ می‌شود
4. برای توقف دوباره `F8`

اگر مدل نصب نباشد، موقع زدن F8 پرسیده می‌شود:
```
مدل:    Whisper small
حجم:    حدود 480 مگابایت
منبع:   huggingface.co
حالا دانلود کنم؟
```

دانلود داخل یک پنجره جدا با نوار پیشرفت انجام می‌شود و قابل لغو است.

### تبدیل نمادهای ریاضی

با گزینه «نمادهای ریاضی» (پیش‌فرض روشن)، کلمات ریاضی به نماد تبدیل می‌شوند:

| فارسی | انگلیسی | نماد |
|---|---|---|
| به علاوه / جمع / اضافه | plus, add | `+` |
| منها / تفریق / کم | minus, subtract | `-` |
| ضرب / حاصل ضرب | times, multiplied by | `*` |
| تقسیم / به لابه / اسلش | divided by, over | `/` |
| مساوی / برابر | equals, equal to | `=` |
| نامساوی / نابرابر | not equal to | `!=` |
| بزرگتر / بیشتر از | greater than, more than | `>` |
| کوچکتر / کمتر از | less than | `<` |
| بزرگتر یا مساوی | greater than or equal to | `>=` |
| کوچکتر یا برابر | less than or equal to | `<=` |
| درصد | percent | `%` |
| ممیز | decimal point | `.` |
| پرانتز باز / بسته | open / close paren | `(` `)` |

نمونه: «بیست سه منها پنج» → `23 - 5` — «صد تقسیم بر چهار» → `100 / 4`

**فقط بین دو عدد تبدیل می‌شود.** چون «منها»، «جمع»، «کم» و «برابر» کلمات عادی
فارسی‌اند، این‌ها بدون عدد در دو طرفشان دست‌نخورده می‌مانند:

| می‌گویید | نتیجه |
|---|---|
| این مال منه | این مال منه |
| جمع کن | جمع کن |
| او بزرگتر است | او بزرگتر است |
| سه درصد رشد | سه درصد رشد |
| one plus my phone | one plus my phone |

### تبدیل اعداد به رقم

با گزینه «اعداد به رقم» (پیش‌فرض روشن)، اعداد گفتاری به رقم تبدیل می‌شوند:

| می‌گویید | نوشته می‌شود |
|---|---|
| بیست سه | `23` |
| صد و بیست و سه | `123` |
| دو هزار | `2000` |
| یک میلیون و دویست هزار | `1200000` |
| بیست و پنج درصد | `25%` |
| دو ممیز پنج | `2.5` |
| هزار و سیصد و هشتاد و پنج | `1385` |
| twenty three (در حالت انگلیسی) | `23` |

مواردی که **دست‌نخورده** می‌مانند: «سه‌شنبه»، «یکی»، «هزاران»، «صدا»، و «نه» به‌تنهایی
(چون «نه» یعنی «not»).

اگر می‌خواهی عددها به حرف نوشته شوند، این گزینه را خاموش کن.

## گزینه‌ها

- **نوشتن مستقیم** — متن بلافاصله در برنامه فعال تایپ می‌شود (با کلیپورد)
- **ارسال Enter** — بعد از هر جمله Enter زده می‌شود
- **نقطه‌گذاری** — اگر جمله نشانه پایان نداشته باشد اضافه می‌شود (`،` برای فارسی)
- **اعداد به رقم** — اعداد گفتاری به رقم تبدیل می‌شوند (پیش‌فرض روشن)
- **نمادهای ریاضی** — کلمات ریاضی به نماد تبدیل می‌شوند (پیش‌فرض روشن)
- **همیشه رو** — پنجره روی بقیه پنجره‌ها می‌ماند
- **تشخیص خودکار زبان** — Whisper خودش زبان را تشخیص می‌دهد (کمی کندتر)

تنظیمات پیشرفته (پنجره «تنظیمات»):

| گزینه | پیش‌فرض | توضیح |
|---|---|---|
| سکوت پایان جمله | 0.9 ثانیه | کمتر = سریع‌تر ولی تکه‌تکه‌تر |
| حداقل طول گفتار | 0.4 ثانیه | جلوگیری از تشخیص صداهای کوتاه |
| حداکثر طول جمله | 14 ثانیه | جمله‌های بلند اینجا شکسته می‌شوند |

## نکات دقت فارسی

- **مدل `small` یا `medium` بهترین نتیجه را می‌دهد.** `tiny` برای فارسی ضعیف است.
- محیط ساکت و میکروفون نزدیک، مهم‌ترین عامل است.
- اعداد را به شکل «بیست سه» بگویید تا درست نوشته شود.
- حروف عربی (ی، ک) خودکار به فارسی (ی، ک) تبدیل می‌شوند.
- اگر جمله‌ها تکه‌تکه شد → «سکوت پایان جمله» را کم کنید.
- اگر کلمه‌ها به هم چسبیده شد → آن مقدار را زیاد کنید.
- دکمه «تست میکروفون» سطح صدای ورودی را نشان می‌دهد.

|---|---|

```
%USERPROFILE%\.voice_typing_config.json
%USERPROFILE%\.voice_typing.log
```

## خط فرمان (اختیاری)

```bash
python download_models.py --list                          # وضعیت مدل‌ها
python download_models.py --engine whisper --size small   # دانلود Whisper
python download_models.py --engine vosk --lang fa         # دانلود Vosk فارسی
```

## عیب‌یابی

**«مدل نصب نیست»**
دکمه «مدل آفلاین» را بزنید و تایید کنید.

**«پکیج نصب نیست»**
```bash
pip install faster-whisper     # یا: pip install vosk
```

**متن نوشته نمی‌شود**
دکمه «تست میکروفون» را بزنید. اگر صدا کم بود، نزدیک‌تر حرف بزنید.
گزینه «نوشتن مستقیم» باید روشن باشد.

**میکروفون کار نمی‌کند**
```bash
pip install pyaudio
```
در ویندوز ممکن است `Microsoft Visual C++ Redistributable` لازم باشد.

**برنامه هنگام اجرا بسته می‌شود**
لاگ را ببینید:
```
%USERPROFILE%\.voice_typing.log
```
