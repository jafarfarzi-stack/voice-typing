Add Windows installer scripts and fix two bugs found while packaging

Installer
- install.bat: finds Python 3.9+, creates a .venv, installs the
  requirements, creates the desktop shortcut and launches the app
- uninstall.bat: removes the venv and shortcut, asks before deleting
  downloaded models, keeps settings and log
- make_shortcut.ps1 now accepts -PythonPath so the shortcut can point at
  the venv interpreter rather than the system one, and falls back to
  .venv automatically
- .gitignore excludes build output (*.exe, dist/, build/, *.spec)

Fixes
- app.py: _set_listening_ui passed the Progressbar widget itself to the
  UI queue, but a widget is not callable. This raised TypeError in the
  queue pump every time listening started or stopped, which aborted the
  rest of that batch. Now posts the start/stop bound method.
- offline_stt.py: backend_available only caught ImportError, so a Vosk
  install whose DLLs could not be loaded raised FileNotFoundError and
  killed the app on startup instead of falling back to another engine.
  Now catches any exception and logs it.
